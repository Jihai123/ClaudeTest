# 中国城市竞争力排行数据导入指南

## 📊 数据格式说明

CSV文件包含以下字段：

| 字段名 | 说明 | 示例 |
|--------|------|------|
| 城市 | 城市名称 | 深圳 |
| 综合经济竞争力指数 | 经济竞争力指数（0-1） | 1 |
| 综合经济竞争力排名 | 经济排名 | 1 |
| 宜居竞争力指数 | 宜居指数（0-1） | 0.795 |
| 宜居竞争力排名 | 宜居排名 | 7 |
| 可持续竞争力指数 | 可持续发展指数（0-1） | 0.922 |
| 可持续竞争力排名 | 可持续发展排名 | 3 |

## 📁 文件位置

- **CSV数据文件**: `data/city-competitiveness-ranking.csv`
- **导入脚本**: `import-city-competitiveness.js`

## 🚀 使用方法

### 方法1：直接导入示例数据

```bash
node import-city-competitiveness.js
```

### 方法2：导入自定义CSV文件

1. 编辑 `data/city-competitiveness-ranking.csv` 文件，按照格式填入你的数据：

```csv
城市,综合经济竞争力指数,综合经济竞争力排名,宜居竞争力指数,宜居竞争力排名,可持续竞争力指数,可持续竞争力排名
深圳,1,1,0.795,7,0.922,3
香港,0.881,2,1,1,1,1
上海,0.747,3,0.756,10,0.989,2
```

2. 运行导入脚本：

```bash
node import-city-competitiveness.js
```

## 📈 评分规则

导入脚本会自动计算：

1. **综合评分** = 经济指数×35% + 宜居指数×40% + 可持续指数×25%（转换为10分制）

2. **城市等级**：
   - tier1: 北京、上海、广州、深圳
   - tier2: 经济排名前15的其他城市
   - tier3: 其他城市

3. **自动标签**：
   - 💼 经济强市（经济排名≤5）
   - 🏡 高度宜居（宜居排名≤5）
   - 🌱 可持续发展（可持续排名≤5）
   - ⭐ 综合实力强（经济和宜居均≤10）

## 🔄 数据更新机制

- 如果城市已存在，会更新其评分、标签和维度数据
- 如果城市不存在，会创建新的城市记录
- 所有导入的城市会被标记为 `china_general` 榜单类型

## 💡 注意事项

1. CSV文件必须使用UTF-8编码
2. 第一行必须是表头
3. 指数值应在0-1之间
4. 排名应为正整数
5. 确保数据库已初始化（首次运行时会自动初始化）

## 🛠️ 维护数据

如需更新数据，只需：
1. 修改CSV文件
2. 重新运行导入脚本
3. 已存在的城市会被更新，新城市会被添加
