# 宜居城市小程序

这是一个帮助用户快速找到理想旅居、养老城市的微信小程序，提供城市评分、用户评价、城市对比等功能。

## 功能特点

### 1. 城市列表
- 展示所有城市的综合评分和各项指标
- 支持搜索城市名称或省份
- 支持按评分、人口等多种方式排序
- 分页浏览，流畅体验

### 2. 城市详情
- 查看城市的详细信息（人口、GDP、面积等）
- 多维度评分展示（生活成本、空气质量、医疗设施、就业机会、安全指数、养老适合度）
- 用户评价列表
- 支持对城市进行评分和评论

### 3. 城市对比
- 最多选择5个城市进行对比
- 直观的条形图展示综合评分
- 详细的数据对比表格
- 支持分享对比结果

### 4. 我的评价
- 查看自己发表的所有评价
- 管理和删除评价
- 用户登录/注册功能

## 技术栈

- 微信小程序原生开发
- 数据通过API与网站后端共享
- 响应式设计，适配各种屏幕尺寸

## 快速开始

### 1. 配置API地址

在 `miniprogram/app.js` 中配置后端API地址：

```javascript
globalData: {
  apiBaseUrl: 'https://your-domain.com/api' // 修改为实际的API地址
}
```

### 2. 配置小程序AppID

在 `miniprogram/project.config.json` 中配置小程序AppID：

```json
{
  "appid": "your-appid-here"
}
```

### 3. 上传图标资源

需要在 `miniprogram/images/` 目录下准备以下图标（建议尺寸81x81px）：

- `home.png` - 首页图标（未选中）
- `home-active.png` - 首页图标（选中）
- `compare.png` - 对比图标（未选中）
- `compare-active.png` - 对比图标（选中）
- `user.png` - 我的图标（未选中）
- `user-active.png` - 我的图标（选中）

### 4. 使用微信开发者工具打开项目

1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 使用微信扫码登录
3. 选择"导入项目"
4. 选择 `miniprogram` 目录
5. 填写AppID
6. 点击"导入"

### 5. 预览和调试

在微信开发者工具中可以：
- 在模拟器中预览小程序
- 使用真机调试功能在手机上测试
- 查看控制台日志和网络请求
- 调试样式和布局

## 数据说明

### 城市数据字段

- `id` - 城市ID
- `name` - 城市名称
- `province` - 省份
- `population` - 人口
- `gdp` - GDP（亿元）
- `area` - 面积（平方公里）
- `overall_score` - 综合评分（0-10）
- `living_cost` - 生活成本评分（0-10）
- `air_quality` - 空气质量评分（0-10）
- `medical_facilities` - 医疗设施评分（0-10）
- `employment` - 就业机会评分（0-10）
- `safety` - 安全指数评分（0-10）
- `elderly_care` - 养老适合度评分（0-10）

### 评价数据字段

- `id` - 评价ID
- `city_id` - 城市ID
- `user_id` - 用户ID
- `rating` - 评分（1-5星）
- `comment` - 评论内容
- `likes` - 点赞数
- `created_at` - 创建时间

## 主要功能说明

### 搜索功能
用户可以通过搜索框输入城市名称或省份进行搜索，支持模糊匹配。

### 排序功能
支持按以下方式排序：
- 综合评分（默认）
- 城市名称
- 人口数量
- 创建时间

### 评分系统
用户可以对城市进行1-5星评分，并添加评论。评分会影响城市的综合评分。

### 对比功能
用户最多可以选择5个城市进行对比，系统会展示：
- 综合评分条形图
- 各项维度详细对比表
- 基本信息对比
